Privacy
Telemetry: none No analytics, no crash upload, no phone-home, no account. Flotilla makes exactly two kinds of outbound connection: to your own hosts, and to GitHub when you ask it to check for an update. by design
There is no VM to size. Apple container runs one micro-VM per container, so the CPU / RAM / disk slider pane that Docker, OrbStack and Colima all have has no analogue here. What exists instead is defaults for new containers, plus per-run flags. Faking a slider would be inventing a control that does nothing.

Precedence: built-in defaults < managed “defaults” seed < your setting < per-host override < managed “locked”. Every setting is a named typed key, which is also what lets the client read and write a remote host's settings with two Wire messages.

Settings — a separate window with six panes. Roughly OrbStack's budget of knobs, not Docker's thirteen tabs, and every control here answers a question the research says a menu-bar fleet app must answer.
